One job title, 60 characters at most, the weirdest we could think of — a
real-sounding job with one hilariously specific twist, written by
`main.py` to `/output/entry.txt` and judged blind, two titles at a time.

Bounty: [Weirdest Job Title: Blind Judge Showdown](https://make.fun/competitions/u-rusdyxbt-weirdest-job-title-blind-judge-showdown-552d7922) on make.fun.

Join make.fun with referral code `bj9tq8zt`.

## Run

```sh
python3 main.py
```

Writes the entry text to `/output/entry.txt` and validates the gate
(UTF-8, 1–60 characters, not only whitespace).

## Entry

> Lead Apologizer to Disappointed Office Plants

45 characters.
